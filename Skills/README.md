# Skills

Reusable skills for backend development and software architecture.

## Available Skills

| Skill | Description |
|---|---|
| [code-reviewer](code-reviewer/SKILL.md) | Review backend code for quality, security, performance, and maintainability. |
| [fix-issues](fix-issues/SKILL.md) | Diagnose and fix backend bugs systematically. |
| [message-queue](message-queue/SKILL.md) | Design and implement BullMQ, AWS SQS, and Agenda message queue systems. |
| [multi-agents](multi-agents/SKILL.md) | Coordinate multiple agents on cross-cutting software work. |
| [multi-tenant](multi-tenant/SKILL.md) | Design multi-tenant applications with tenant isolation and scoped resources. |
| [project-architect](project-architect/SKILL.md) | Design and review production-grade backend architecture. |
| [unit-test](unit-test/SKILL.md) | Generate comprehensive unit tests for backend code. |

## Installation

Install all skills in your project:

```powershell
pnpx skills add elrefai99/use --skill="*"
```

Install them globally:

```powershell
pnpx skills add elrefai99/use --skill="*" -g
```

Learn more about the CLI usage at [skills](https://github.com/vercel-labs/skills).
